Designed, drawn, and reviewed for version 1.0.
The physical constraints on this board are unforgiving:
→ BQ76930 battery monitor IC at the core 
→ XT60 connectors for main input and load output
→ Dedicated charge and discharge MOSFETs → Hardware-level telemetry headers
