Smart Lighting System with Obstacle Detection

Technologies: Altium Designer, ATMEGA328PB-AU, VL53L0X ToF Sensor, TP4056, USB-C

Overview

Designed and engineered a custom printed circuit board for an automated lighting solution. The system utilizes an ATMEGA328PB-AU microcontroller and a VL53L0X Time-of-Flight sensor to provide precise distance tracking and responsive illumination.

Key Features

  • Custom PCB Design: Developed the schematic and routed the board using Altium Designer, focusing on optimized power delivery.
  • Precision Sensing: Integrated a VL53L0X Time-of-Flight sensor for accurate obstacle detection.
  • Custom Illumination: Engineered independently controlled dual LED arrays (White and Yellow) for versatile lighting outputs.
  • Power Management: Implemented a dedicated TP4056-based USB-C charging circuit to ensure safe and efficient power handling.

Omni-Sense Node: Mixed-Signal DAQ

Technologies: ESP32, SPI, PWM, RC522 RFID, MQ-Series Sensors

Overview

Developed a centralized Data Acquisition (DAQ) and control system using an ESP32 microcontroller, integrating 15 heterogeneous peripheral devices. The project focuses on solving hardware-level challenges such as power distribution, signal integrity, and multi-protocol data handling in a mixed-signal environment.

Key Features

  • Power Architecture & Logic Compliance: Engineered a dual-rail power distribution network to safely isolate high-current 5V loads from 3.3V logic components, implementing voltage divider networks for safe logic-level compliance.
  • I/O Optimization & Telemetry: Strategically mapped all continuous analog sensor acquisitions to the ESP32's ADC1 hardware to bypass structural conflicts with internal Wi-Fi drivers, ensuring uninterrupted telemetry.
  • Multi-Protocol Integration: Successfully managed asynchronous data streams and control signals across multiple protocols, including SPI (RC522 RFID), PWM (Servo actuation), and raw Analog/Digital discrete I/O.
  • Signal Integrity: Mitigated electromechanical noise and inductive kickback from actuators using localized decoupling and strict ground-plane management to prevent MCU brownouts.

Mixed-Signal RF Transceiver Board

Technologies: ESP32, RF TX/RX, 50Ω Impedance, Signal Integrity

Overview

Wrapped up the layout for a new mixed-signal RF transceiver board, solving signal integrity challenges by integrating a noisy digital ESP32 module with highly sensitive RF TX/RX chains.

Key Features

  • Impedance Control: Routed RF pathways with a strict 50Ω impedance profile (17.6 mil trace width).
  • Noise Mitigation: Implemented a unified ground plane strategy and built a complete Faraday cage using continuous polygon pours and exactly 312 stitching vias.
  • Signal Leakage Prevention: Added coplanar waveguide via fencing along the RF lines.
  • Wi-Fi/Bluetooth Performance: Enforced a strict copper keepout beneath the ESP32 antenna to ensure unattenuated wireless performance.

IncliSense Precision Digital Level

Technologies: Arduino Nano, MPU6050, 3D Printing (ABS), PC Telemetry

Overview

The IncliSense project is a precision digital leveling device built to provide high-accuracy numerical feedback, improving upon traditional mechanical levels.

Key Features

  • Hardware: Driven by an Arduino Nano and an MPU6050 accelerometer/gyroscope.
  • Data Processing: Processes dual-axis spatial data to trigger a responsive interface of 11 LEDs and an integrated buzzer.
  • Enclosure: Housed in a custom 3D-printed ABS enclosure.
  • Connectivity: Features PC telemetry for IoT connectivity, making it a robust, industrial-grade engineering prototype.
